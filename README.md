# 🏨 Hotel IT Academy

## منصة أكاديمية المعلوماتية الفندقية

منصة تعليمية شاملة وحديثة لتعليم تقنيات المعلوماتية في الفنادق باستخدام محاكيات واقعية وتمارين تفاعلية.

### 🎯 المميزات الرئيسية

#### 📚 1. الدروس المتقدمة
- 10 وحدات تعليمية شاملة
- من أساسيات الحاسوب إلى أنظمة إدارة الفنادق
- محتوى عربي وإنجليزي

#### 🧪 2. المختبر العملي
- تمارين تفاعلية من بيئة الفندق الفعلية
- سيناريوهات واقعية للتعلم العملي
- ردود فعل فورية وتقييم ذكي

#### 🏨 3. محاكاة نظام إدارة الفندق (PMS)
- محاكاة واقعية لنظام إدارة الفندق
- إدارة الحجوزات والعملاء
- تتبع حالة الغرف والفواتير

#### 🍽️ 4. محاكاة نظام نقطة البيع (POS)
- نظام محاكى لمطعم الفندق
- إدارة الطلبات والمبيعات
- تقارير المخزون والإيرادات

#### 📊 5. الاختبارات الذكية
- اختبارات سريعة وشاملة
- تحليل ذكي لنقاط الضعف
- توصيات شخصية للمراجعة

#### 🏆 6. نظام التصنيف والتحفيز
- نظام نقاط XP شامل
- مستويات تقدم متعددة
- شارات وإنجازات
- لوحة متصدرين

#### 👨‍🏫 7. لوحة تحكم المدرس
- إدارة الطلاب والمجموعات
- بنك أسئلة ديناميكي
- تقارير أداء مفصلة
- متابعة التقدم الفردي

### 🛠️ التكنولوجيا المستخدمة

- **Frontend**: Next.js 14 + React 18 + TypeScript
- **Styling**: Tailwind CSS
- **State Management**: Zustand
- **Charts**: Chart.js + React-ChartJS-2
- **HTTP Client**: Axios
- **Icons**: React Icons
- **Dates**: Date-FNS

### 🚀 البدء السريع

#### المتطلبات
- Node.js 16+ 
- npm أو yarn

#### التثبيت

```bash
# استنساخ المستودع
git clone https://github.com/Bshaarr/my_flutter_project.git
cd my_flutter_project

# التبديل إلى فرع المشروع
git checkout hotel-it-academy

# تثبيت المكتبات
npm install
```

#### التشغيل

```bash
# وضع التطوير
npm run dev

# سيتم فتح الموقع على http://localhost:3000
```

#### البناء للإنتاج

```bash
npm run build
npm start
```

# 🏨 Hotel IT Academy
## منصة أكاديمية المعلوماتية الفندقية

منصة تعليمية تفاعلية متخصصة في تعليم تقنيات المعلوماتية والحاسوب بربطها مباشرة مع تطبيقات الفنادق والضيافة.

### ✨ الميزات الرئيسية

- 📚 **الدروس التفاعلية** - محتوى منظم على وحدات
- 🧪 **المختبر العملي** - تمارين عملية مع تقييم فوري
- 🏨 **محاكاة الفندق** - نظام PMS افتراضي
- 🍽️ **محاكاة المطعم** - نظام POS افتراضي
- 📊 **تقدم الطالب** - تحليل شامل للأداء
- 🏆 **نظام الألعاب** - نقاط وشارات وتحديات
- 👨‍🏫 **لوحة تحكم المدرس** - إدارة كاملة للفصل
- 📖 **بنك الأسئلة** - إدارة ديناميكية للاختبارات

### 🚀 البدء السريع

```bash
# استنساخ المستودع
git clone https://github.com/Bshaarr/my_flutter_project.git
cd my_flutter_project

# تثبيت المتطلبات - Frontend
cd frontend
npm install
npm run dev

# في نافذة جديدة - Backend
cd ../backend
npm install
npm run dev
```

### 🛠️ التقنيات المستخدمة

**Frontend:**
- React + TypeScript
- Tailwind CSS
- Vite
- Zustand (State Management)
- React Router v6

**Backend:**
- Node.js + Express
- TypeScript
- MongoDB + Mongoose
- JWT Authentication
- CORS enabled
